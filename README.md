静态个人主页：About / Projects / Experience / Research / Awards，深浅色与中英文一键切换（◐ / En），并提供不使用追踪 Cookie 的匿名聚合访问统计。

## 页面结构

| 文件 | 内容 |
|---|---|
| `index.html` | 主页（关于我、兴趣方向、项目与经历入口） |
| `cv.html` | 中文简历 |
| `cv-en.html` | 英文简历及 PDF 下载 |
| `mcm-paper.html` | 数学建模论文 |
| `qiushi-paper.html` | 求是杯论文 |
| `styles.css` / `script.js` | 样式与交互（深色模式、中英文切换） |
| `analytics.js` | 页面访问与点击事件上报 |
| `analytics/` | Cloudflare Worker、D1 聚合统计与 Dashboard |
| `assets/` | 图片等静态资源 |

## 本地预览与部署

纯静态、零构建：直接打开 `index.html`。线上版由 GitHub Pages 托管（main 分支根目录）。
